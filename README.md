# autodesk-mcp

MCP servers that let Claude work with Revit 2027 and AutoCAD 2027, with a token-lean design.

- `revit/`: Revit 2027 add-in + MCP bridge ([README](revit/README.md))
- `autocad/`: AutoCAD 2027 plugin + MCP bridge ([README](autocad/README.md))
- `shared/mcp-conventions.md`: the contract both servers follow
